# 婚礼和旅拍视频剪辑

先确认成片给谁看、放在哪里、有哪些必留的人或地点、预计时长，以及有哪些可用录音和配乐。已有答案直接沿用。只有场记或文字时，可以先出带素材编号的纸上剪辑方案，将待听、待看的项目标清。收到原素材后，把记录补到真实文件和时码。

## 选路径

- **婚礼快剪**从仪式连续录音和一次性事件入手。按真实原句把讲话者、同一刻的听者和反应机位连起来；婚礼全纪录的承诺镜头与精华片的取舍分别记录。用[婚礼工作流](references/wedding.md)做选片、同步核验和双版精剪。
- **旅拍短片**从一条能讲明白的路线入手。每到一处找一个位置线索、一个人物动作和一段当地声音。用[旅拍工作流](references/travel.md)处理方向、声桥、光线和双人移动时的竖版构图。
- **目的地婚礼**可同时用两份指南。例如婚礼主片保留誓词与回应，旅拍预告围绕新人穿行当地的一次行动。共用源素材编号，分别建立版别、声轨、字幕和入出点。

两个候选切点都接得顺，或熟悉素材的人已很难判断地点是否交代清楚时，用[两位电影剪辑师的方法与剪辑练习](references/editors.md)做一次替换试听或初看测试。

## 从素材到双版

1. 遍历原片和外录。用 `scripts/review.py inventory` 量出规格与整段响度，随后看画面、听同期声。给被选的每段标出源入出点、用途、可辨认的人或地点、替代镜头，注明录音是否干净。保留原文件。
2. 先做声音和画面的纸上剪辑。把必须听完的原句或现场声落到时间线上，再把原镜、反应和细节接上去。横版与竖版共享候选池，分别决定首镜、顺序、时长与声画切点。交付单版时只写实际需要的版本。
3. 按[计划格式和命令](references/plan.md)填写每版的 `cuts`。用 `edit_plan.py --timeline` 得到源时码与成片帧的对照，用 `review.py sheet` 检查各镜头前、中、后三帧，再播放移动、遮挡和手部动作的整个区间。一个裁框装不下主体时，换镜、缩短选段或保全幅。
4. 在剪辑软件中完成需要的多机同步、声音修复、逐镜校色以及誓词转写。把已对齐的主声轨和本版 SRT 交给渲染器。按这句话或这个动作在成片里的起止时间写配乐压低区间。画面剪定后做最终混音。[声音、画面与手机复查](references/finishing.md)
5. 需要预览时用 `scripts/render.py` 的 `draft` 模式。按交付尺寸输出横版或竖版，回读实际分辨率、帧率、时长与响度，核对承诺镜头和字幕。只交付已生成且能打开的文件。用户只要建议或清单时，交付对应结果即可。

需要可执行的起点时，`scripts/make_demo.py` 会在指定的新目录生成两份计划和本地测试图声。真实客片可以从 [婚礼计划](assets/examples/wedding.json) 或 [旅拍计划](assets/examples/travel.json) 换片开始。
